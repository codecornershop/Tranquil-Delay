# Tranquil Delay

A simple, clean Delay VST3 built with JUCE.
I don't know who this is for just yet, every delay i've used kind of overcomplicates the process (which i most likely will do too as i continue to develop this).
This is a ridiculously simple delay. It just does the echo thing. It's meant to be an educational process for me but if it can be useful to someone, then why not?
Enjoy.

## Features
- Tempo Sync with 12 divisions
- Clear Buffer toggle

## Build
- Requires JUCE 7+
- Open Projucer file and export
- Or run `make` in the build folder (if you're on Linux)
